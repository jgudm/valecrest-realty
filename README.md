# Valecrest Realty

A concept website for a fictional real estate company, built from scratch with Claude Code.

- Plain HTML, CSS and JavaScript, with no build step
- Working listing search by location, type and budget
- Booking form with validation (demo only, nothing is sent)
- Building drawings made as inline SVG, so no stock photos are used
- Mobile-first layout

Run it locally:

```bash
python3 -m http.server 4173
```
